# TradeX Simulated Cryptocurrency Trading System

A user-friendly platform for learning and practicing cryptocurrency trading without real financial risk.

## Project Overview

TradeX allows users to practice cryptocurrency trading, explore market data, and refine their trading strategies in a simulated environment.

## Technologies

- React JS
- Node JS
- PostgreSQL
